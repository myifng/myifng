# Phase 11: पाठक खाते, टिप्पणियाँ, पोल, न्यूज़लेटर, नोटिफ़िकेशन सेंटर

## 1. लक्ष्य

**पाठक खाते (§47, §48)** — वैकल्पिक (सेटिंग से चालू/बंद)

- पाठक का अलग खाता (`readers` टेबल; एडमिन/स्टाफ़ के `users` से पूरी तरह अलग, अलग सत्र): रजिस्टर, ईमेल सत्यापन, लॉगिन, पासवर्ड भूले, प्रोफ़ाइल, पासवर्ड बदलें, खाता हटाएँ (अपना डेटा मिटाने का अधिकार)।
- **सेव/बुकमार्क**, **फ़ॉलो**: श्रेणी, रिपोर्टर, शहर (लोकेशन), टॉपिक; **पढ़ने का इतिहास** (बंद भी कर सकते हैं); **सूचना पसंद** (ब्रेकिंग, ई-पेपर, फ़ॉलो की गई चीज़ें, न्यूज़लेटर; ईमेल/पुश)।
- **"आपके लिए"** पेज: फ़ॉलो की गई श्रेणी/रिपोर्टर/शहर/टॉपिक की ताज़ा ख़बरें + "आपके शहर में लोकप्रिय"। कोई छुपा हुआ एल्गोरिदम नहीं; सिर्फ़ पाठक ने जो चुना।

**टिप्पणियाँ (§45)**

- ख़बर के नीचे टिप्पणियाँ; एक स्तर के जवाब; सेटिंग: चालू/बंद, मेहमान (नाम+ईमेल) या सिर्फ़ लॉगिन पाठक, मॉडरेशन (सब पहले जाँच / भरोसेमंद पाठक सीधे / सब सीधे)।
- हर ख़बर पर टिप्पणी चालू/बंद (एडिटर में)।
- स्थितियाँ: **पेंडिंग, स्वीकृत, स्पैम, अस्वीकृत**; **ब्लॉक** (ईमेल / IP / पाठक / शब्द)।
- स्पैम से बचाव: honeypot, बहुत जल्दी भेजा गया फ़ॉर्म, लिंक की गिनती, रोके गए शब्द, एक IP से सीमा (throttle)।
- एडमिन: स्थिति के टैब, बल्क स्वीकृत/स्पैम/हटाएँ, संपादक का जवाब, लेखक को ब्लॉक।

**पोल (§46)**

- सवाल, विकल्प (2-10), शुरू/ख़त्म, एक या कई विकल्प, नतीजे कब दिखें (हमेशा / वोट के बाद / ख़त्म होने पर), लॉगिन ज़रूरी या नहीं, स्थिति।
- दुरुपयोग रोक: एक ब्राउज़र/IP से एक वोट (हैश, असली IP सेव नहीं), पाठक खाते से एक वोट, बॉट नहीं, throttle, CSRF।
- ख़बर/पेज में `[poll:ID]`, होमपेज "पोल" ब्लॉक, अलग पेज `/poll/{id}`; एडमिन में नतीजे (ग्राफ़) और CSV।

**न्यूज़लेटर (§51)**

- **सब्सक्राइबर** (डबल ऑप्ट-इन: पुष्टि लिंक), **सूचियाँ** (जैसे "रोज़ सुबह", "खेल"; श्रेणी से जोड़ने लायक), **टेम्पलेट** (HTML, `{{content}}`, `{{unsubscribe_url}}` जैसे खाने), **कैंपेन** (विषय, सामग्री, "आज की टॉप ख़बरें" अपने आप, सूचियाँ, टेस्ट ईमेल, तुरंत/तय समय पर भेजें), **अनसब्सक्राइब** (एक क्लिक, हेडर `List-Unsubscribe`)।
- Shared hosting पर भेजना: कतार; हर मिनट कुछ ईमेल (सेटिंग), cron की ज़रूरत नहीं।
- होमपेज "न्यूज़लेटर" ब्लॉक और फ़ुटर फ़ॉर्म; CSV इंपोर्ट/एक्सपोर्ट।

**नोटिफ़िकेशन सेंटर (§50)**

- एक इंजन, कई चैनल: **इन-ऐप** (एडमिन की घंटी, पाठक के खाते में), **ईमेल**, **वेब पुश** (VAPID, बिना किसी कंपनी के SDK), **SMS-ready**, **WhatsApp-ready** (ड्राइवर: लॉग या अपना HTTP API; कोई एक प्रोवाइडर हार्डकोड नहीं)।
- इवेंट: ब्रेकिंग न्यूज़, ई-पेपर प्रकाशित, रिपोर्टर स्वीकृत, ख़बर स्वीकृत/लौटाई, नया असाइनमेंट, दस्तावेज़ की वैधता ख़त्म होने वाली; हर इवेंट के चैनल सेटिंग से।
- कतार (outbox) + दोबारा कोशिश; लॉग पेज; एडमिन से हाथ से पुश/सूचना भेजना।

| `reader_bookmarks` | reader_id, news_id |

| `comments` | news_id, parent_id, reader_id, user_id, name, email, body, status, ip_hash, user_agent, approved_by |
| `comment_blocks` | type (email/ip/reader/word), value, note |
| `polls`, `poll_options`, `poll_votes` | सवाल, विकल्प, हर वोट (voter_hash, reader_id) |
| `newsletter_lists`, `newsletter_subscribers`, `newsletter_list_subscribers` | सूचियाँ, सब्सक्राइबर (status, token), जोड़ |

## 3. रूट (मुख्य)

| पता | काम |
|---|---|
| `/account/login`, `/account/register`, `/account/verify/{token}`, `/account/forgot`, `/account/reset/{token}` | पाठक खाता |
| `/account`, `/account/saved`, `/account/history`, `/account/following`, `/account/notifications`, `/account/settings` | "आपके लिए", सेव, इतिहास, फ़ॉलो, सूचनाएँ, सेटिंग |
| `POST /account/bookmark/{id}`, `POST /account/follow` | सेव/फ़ॉलो (AJAX भी) |
| `POST /news/{slug}/comments` | टिप्पणी |
| `/poll/{id}`, `POST /poll/{id}/vote` | पोल |
| `POST /newsletter`, `/newsletter/confirm/{token}`, `/newsletter/unsubscribe/{token}` | न्यूज़लेटर |
| `/sw.js`, `POST /push/subscribe`, `POST /push/unsubscribe` | वेब पुश |
| `/admin/comments…`, `/admin/polls…`, `/admin/newsletter…`, `/admin/readers…`, `/admin/notifications…` | एडमिन |

## 4. अनुमतियाँ

पहले से मौजूद: `comments.view/edit/delete/approve`, `polls.*` + `polls.publish`, `newsletter.*` + `export/manage`, `readers.view/edit/delete/export`, `notifications.view/create/manage`। Admin को सब; Editor को टिप्पणियाँ और पोल (`comments.*`, `polls.*`, रोल की मूल सेटिंग से; पुरानी साइट पर migration भी जोड़ता है)। हर स्टाफ़ यूज़र अपनी घंटी की सूचनाएँ देखता है।

## 5. सुरक्षा

| जोखिम | उपाय |
|---|---|
| पाठक और स्टाफ़ का सत्र मिलना | अलग टेबल, अलग सत्र कुंजी; पाठक कभी एडमिन नहीं खोल सकता |
| पासवर्ड/खाता | `password_hash`, लॉगिन throttle, सत्यापन/रीसेट टोकन का सिर्फ़ हैश सेव, 60 मिनट/24 घंटे की वैधता, लॉगिन पर session ID बदले |
| टिप्पणी में XSS/स्पैम | सादा टेक्स्ट (HTML/लिंक नहीं बनते), honeypot, समय जाँच, throttle, ब्लॉक सूची, मॉडरेशन |
| नकली वोट | एक वोट (ब्राउज़र+IP हैश / पाठक), बॉट नहीं, throttle |
| न्यूज़लेटर का दुरुपयोग | डबल ऑप्ट-इन, हर ईमेल में अनसब्सक्राइब, कोई ईमेल पता सार्वजनिक नहीं, throttle |
| पुश | VAPID निजी कुंजी सिर्फ़ सर्वर पर; ग़लत/पुराने सब्सक्रिप्शन अपने आप हटते हैं |
| निजता | IP का सिर्फ़ हैश; पाठक इतिहास बंद/मिटा सकता है और खाता हटा सकता है |

## 6. जाँच के नतीजे

| जाँच | नतीजा |
|---|---|
| PHP/JS सिंटैक्स | सारी नई/बदली फ़ाइलें `php -l` पास; app.js, admin.js पार्स ठीक |
| माइग्रेशन | मौजूदा साइट पर 000011 चला (19 नई टेबल); नया इंस्टॉल (11 माइग्रेशन): डिफ़ॉल्ट सूची + टेम्पलेट, `news.allow_comments` |
| पाठक खाता | कमज़ोर पासवर्ड रुका; रजिस्टर → सत्यापन ईमेल → लिंक से चालू + लॉगिन; वही लिंक दोबारा बेकार; न्यूज़लेटर चुना था तो साथ में पुष्टि |
| सेव / फ़ॉलो | ख़बर सेव/हटाना (AJAX), श्रेणी और शहर (खोजकर) फ़ॉलो; ग़लत लक्ष्य रुका; बिना लॉगिन → 401 + लॉगिन पेज |
| "आपके लिए" | फ़ॉलो की गई श्रेणी/शहर की 12 ख़बरें + पेज; इतिहास, सूचनाएँ, सेटिंग पेज |
| टिप्पणी | बहुत जल्दी भेजा फ़ॉर्म रुका; 3 लिंक वाली → स्पैम; honeypot → चुपचाप; मेहमान → पेंडिंग; मॉडरेटरों को घंटी; स्वीकृति/जवाब पर पाठक को सूचना |
| मॉडरेशन | स्वीकृत/स्पैम/अस्वीकृत/हटाना, संपादक का जवाब (बैज के साथ), ईमेल ब्लॉक → उसकी टिप्पणियाँ स्पैम |
| पोल | एक विकल्प वाले पोल में दो विकल्प रुके; वोट → नतीजे (AJAX); दोबारा वोट, नई कुकी से भी (IP+ब्राउज़र हैश), बॉट: सब रुके; 1 विकल्प वाला पोल सेव नहीं |
| न्यूज़लेटर | डबल ऑप्ट-इन पुष्टि; कैंपेन में `<script>` हटी; टेस्ट ईमेल; भेजें → कतार → प्रोसेस → कैंपेन "भेज दिया"; वन-क्लिक अनसब्सक्राइब (बिना CSRF, सिर्फ़ टोकन) |
| नोटिफ़िकेशन | ख़बर जमा → डेस्क के 3 यूज़र; अस्वीकार/प्रकाशित → रिपोर्टर (घंटी + ईमेल कतार); स्टाफ़ को हाथ से सूचना; घंटी में गिनती/सूची, "सब पढ़ी" |
| वेब पुश | aes128gcm एन्क्रिप्शन का उल्टा (डिक्रिप्ट) टेस्ट पास; VAPID JWT (ES256) 50/50 बार सत्यापित; सब्सक्राइब (ग़लत कुंजी रुकी); कतार → नेटवर्क त्रुटि दर्ज और दोबारा कोशिश |
| अनुमति | Editor: टिप्पणी/पोल हाँ, न्यूज़लेटर/पाठक/सेंटर 403; Reporter: सब 403, अपनी घंटी हाँ; पाठक का सत्र एडमिन नहीं खोलता |
| CSRF | 11 POST रूट बिना टोकन → 419 |
| मोबाइल (390px) | 10 वेबसाइट और 13 एडमिन पेज, कोई साइडवेज़ स्क्रोल नहीं; JS त्रुटि नहीं |

**लाइव सर्वर पर:** ईमेल PHP `mail()` से जाते हैं (इस टेस्ट सर्वर पर mail नहीं, इसलिए वहाँ "विफल" दर्ज हुए)। वेब पुश के लिए HTTPS ज़रूरी है; सेटिंग → नोटिफ़िकेशन में चालू करें। SMS/WhatsApp के लिए अपने प्रोवाइडर का API URL डालें (या "सिर्फ़ लॉग" से टेस्ट करें)।
