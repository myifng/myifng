# शेयर होस्टिंग पर इंस्टॉल गाइड (cPanel)

## 1. फ़ाइलें अपलोड करें
1. cPanel → **File Manager** → `public_html` खोलें।
2. ZIP अपलोड करें → राइट क्लिक → **Extract**।
3. सब-फ़ोल्डर में लगाना हो (जैसे `example.com/news`), तो उसी फ़ोल्डर में extract करें।

## 2. PHP वर्ज़न
cPanel → **Select PHP Version** (या MultiPHP Manager) → **8.1 या नया** चुनें।
Extensions में ये चालू रखें: `pdo_mysql`, `mbstring`, `fileinfo`, `dom`, `gd`, `curl`, `openssl`, `zip`, `intl`।
सलाह: `upload_max_filesize` और `post_max_size` = 64M, `memory_limit` = 256M (ई-पेपर PDF के लिए)।

## 3. डेटाबेस
cPanel → **MySQL Databases**:
1. नया डेटाबेस बनाएँ (जैसे `user_news`)।
2. नया यूज़र बनाएँ, मज़बूत पासवर्ड के साथ।
3. यूज़र को डेटाबेस से जोड़ें → **ALL PRIVILEGES**।

## 4. इंस्टॉल विज़ार्ड
ब्राउज़र में अपना डोमेन खोलें → विज़ार्ड अपने आप `/install/` पर ले जाएगा।

| कदम | क्या करना है |
|---|---|
| 1. सर्वर जाँच | सब PASS/WARNING हो तो आगे बढ़ें। ERROR हो तो ऊपर वाली PHP सेटिंग ठीक करें। |
| 2. डेटाबेस | होस्ट (ज़्यादातर `localhost`), डेटाबेस नाम, यूज़र, पासवर्ड, प्रीफ़िक्स |
| 3. टेबल | "टेबल इंस्टॉल करें" दबाएँ |
| 4. Super Admin | आपका नाम, ईमेल, पासवर्ड (कम से कम 8 अक्षर, अक्षर + अंक) |
| 5. वेबसाइट | नाम, टैगलाइन, URL, लोगो, रंग, टाइमज़ोन, भाषा, एडमिन पैनल का पता |
| 6. डेमो डेटा | चाहें तो डेमो खाते जोड़ें (पासवर्ड अगले पेज पर दिखेगा) |
| 7. पूरा | एडमिन पैनल का लिंक मिलेगा |

## 5. इंस्टॉल के बाद (ज़रूरी)
- सर्वर से **`/install` फ़ोल्डर हटा दें**।
- **SSL** लगाएँ: cPanel → SSL/TLS या AutoSSL।
- डेमो खाते लाइव साइट पर हटा दें: एडमिन → यूज़र।
- `config/env.php` में `DEBUG` हमेशा `false` रखें।

## समस्या और हल

| समस्या | हल |
|---|---|
| एडमिन पेज पर 404 | mod_rewrite बंद है, या सब-फ़ोल्डर में है: `.htaccess` में `RewriteBase /फ़ोल्डर/` वाली लाइन चालू करें |
| "डेटाबेस से कनेक्ट नहीं" | `config/env.php` में DB जानकारी जाँचें |
| अपलोड नहीं हो रहा | `public/uploads` की अनुमति 755; PHP upload सीमा बढ़ाएँ |
| ईमेल नहीं जा रहा (पासवर्ड रीसेट) | होस्टिंग पर PHP mail चालू हो; न जाए तो `storage/logs/mail-*.log` देखें |
| सफ़ेद पेज / 500 | `storage/logs/app-*.log` देखें; ज़रूरत हो तो थोड़ी देर `DEBUG => true` करें |
| दोबारा इंस्टॉल करना | `config/env.php` और `storage/installed.lock` हटाएँ, फिर `/install/` खोलें (डेटा अपने आप नहीं मिटता) |

## लोकल कंप्यूटर पर (XAMPP / Laragon)
प्रोजेक्ट को `htdocs/news` में रखें, `http://localhost/news/` खोलें और वही 7 कदम पूरे करें।
