# शेयर होस्टिंग पर इंस्टॉल गाइड (cPanel / DirectAdmin)

यह सॉफ़्टवेयर साधारण शेयर होस्टिंग पर चलता है: **Composer, Node.js, npm या SSH की ज़रूरत नहीं।**
पूरा इंस्टॉल ब्राउज़र से 10–15 मिनट में हो जाता है।

## 0. ज़रूरतें

| चीज़ | न्यूनतम | सलाह |
|---|---|---|
| PHP | 8.1 | 8.2 या 8.3 |
| डेटाबेस | MySQL 5.7 / MariaDB 10.3 | MySQL 8 / MariaDB 10.6+ |
| ज़रूरी एक्सटेंशन | `pdo`, `pdo_mysql`, `mbstring`, `json`, `fileinfo`, `dom` | |
| सलाह वाले एक्सटेंशन | `gd` (इमेज/WebP), `curl`, `openssl`, `zip` (बैकअप), `intl` | सब चालू रखें |
| वेब सर्वर | Apache / LiteSpeed + `mod_rewrite` | ज़्यादातर होस्टिंग पर पहले से |
| जगह | 100 MB (सॉफ़्टवेयर ~8 MB) | तस्वीरों/ई-पेपर के हिसाब से ज़्यादा |
| PHP सीमाएँ | upload 8M, memory 128M, समय 30 सेकंड | upload 64M, memory 256M, समय 120 सेकंड |

> इंस्टॉल विज़ार्ड का **कदम 1** ये सब अपने-आप जाँचता है और हर चीज़ पर PASS / WARNING / ERROR दिखाता है।

## 1. फ़ाइलें अपलोड करें
1. cPanel → **File Manager** → `public_html` खोलें।
2. **Upload** से ZIP अपलोड करें → ZIP पर राइट क्लिक → **Extract**।
3. ZIP के अंदर की फ़ाइलें (`index.php`, `app/`, `public/` …) सीधे `public_html` में होनी चाहिए, किसी अतिरिक्त फ़ोल्डर में नहीं।
4. **सब-फ़ोल्डर** में लगाना हो (जैसे `example.com/news`), तो `public_html/news` बनाकर उसी में extract करें। सब-फ़ोल्डर अपने-आप पहचाना जाता है।
5. छुपी फ़ाइलें दिखाएँ (File Manager → Settings → *Show Hidden Files*) और देखें कि **`.htaccess`** भी आई है। यही फ़ाइल सुंदर URL और सुरक्षा संभालती है।

### फ़ोल्डर अनुमति (Permissions)
ज़्यादातर होस्टिंग पर कुछ नहीं करना पड़ता। कदम 1 में "लिखने की अनुमति नहीं" दिखे, तो इन फ़ोल्डरों को **755** करें (कुछ पुरानी होस्टिंग पर 775):
`config/`, `storage/` (और इसके अंदर `cache`, `logs`, `sessions`, `private`, `backups`), `public/uploads/`।
**777 कभी न करें।**

## 2. PHP वर्ज़न और सेटिंग
1. cPanel → **Select PHP Version** (या **MultiPHP Manager**) → **8.1 या नया** चुनें।
2. Extensions में ऊपर की सूची वाले एक्सटेंशन चालू करें।
3. सीमाएँ बढ़ाएँ (ई-पेपर PDF, बड़ी तस्वीरें, बैकअप के लिए), दो में से कोई एक तरीका:
   - cPanel → **MultiPHP INI Editor** / *Options* टैब: `upload_max_filesize = 64M`, `post_max_size = 72M`, `memory_limit = 256M`, `max_execution_time = 120`।
   - या ZIP के साथ आई **`user.ini.example`** का नाम बदलकर **`.user.ini`** करें (PHP-FPM / LiteSpeed होस्टिंग पर काम करती है; 5 मिनट में लागू)।

## 3. डेटाबेस बनाएँ
cPanel → **MySQL® Databases**:
1. नया डेटाबेस बनाएँ (जैसे `user_news`)।
2. नया यूज़र बनाएँ, मज़बूत पासवर्ड के साथ (Password Generator इस्तेमाल करें)।
3. *Add User To Database* → यूज़र को डेटाबेस से जोड़ें → **ALL PRIVILEGES**।
4. ये तीनों (डेटाबेस नाम, यूज़र, पासवर्ड) नोट कर लें। cPanel में दोनों के आगे खाते का नाम जुड़ता है (`user_news`)।

## 4. इंस्टॉल विज़ार्ड (7 कदम)
ब्राउज़र में अपना डोमेन खोलें। विज़ार्ड अपने-आप `/install/` पर ले जाएगा।

| कदम | क्या करना है |
|---|---|
| 1. सर्वर जाँच | सब PASS/WARNING हो तो आगे बढ़ें। ERROR हो तो ऊपर वाली PHP सेटिंग या फ़ोल्डर अनुमति ठीक करें। |
| 2. डेटाबेस | होस्ट (ज़्यादातर `localhost`), पोर्ट 3306, डेटाबेस नाम, यूज़र, पासवर्ड, टेबल प्रीफ़िक्स (डिफ़ॉल्ट `np_`; एक डेटाबेस में दो साइट हों तो अलग रखें) |
| 3. टेबल | "टेबल इंस्टॉल करें": सारी टेबल, 29 श्रेणियाँ, मेनू, विज्ञापन स्लॉट, होमपेज सेक्शन, 12 पेज, 112 लोकेशन बनती हैं |
| 4. Super Admin | आपका नाम, ईमेल, मोबाइल, पासवर्ड (कम से कम 8 अक्षर, अक्षर + अंक) |
| 5. वेबसाइट | नाम, टैगलाइन, URL, लोगो, फ़ेविकॉन, रंग, टाइमज़ोन, भाषा, एडमिन पैनल का पता (जैसे `/admin` की जगह कुछ और) |
| 6. डेमो डेटा | चाहें तो नमूना सामग्री जोड़ें (नीचे देखें)। इसमें 5–15 सेकंड लगते हैं |
| 7. पूरा | एडमिन पैनल का लिंक, डेमो पासवर्ड और लाइव करने से पहले की चेकलिस्ट |

विज़ार्ड बीच में रुक जाए (बिजली/नेट), तो दोबारा `/install/` खोलें: कदम 2 में "अधूरा इंस्टॉल जारी रखें" विकल्प आता है।

### डेमो डेटा में क्या आता है
- 31 ख़बरें (तस्वीर, टैग, श्रेणी, ज़िला सहित), 1 लाइव ब्लॉग, 3 ब्रेकिंग न्यूज़
- 4 वीडियो, 2 फ़ोटो गैलरी, 1 वेब स्टोरी, 1 लाइव टीवी चैनल, आज का ई-पेपर (4 पेज)
- 1 पोल, 1 फ़ैक्ट चेक, 2 नौकरियाँ, 4 विज्ञापन
- 5 डेमो खाते (admin.demo, editor.demo, reporter.demo, reporter2.demo, employee.demo `@example.com`) और 2 रिपोर्टर प्रोफ़ाइल (ID कार्ड सहित)
- सारी तस्वीरें सॉफ़्टवेयर ख़ुद बनाता है (कोई कॉपीराइट वाली फ़ोटो नहीं)।

**हटाना:** एडमिन → **सिस्टम** → **"डेमो डेटा हटाएँ"**। एक क्लिक में सारी डेमो पंक्तियाँ और उनकी तस्वीरें हट जाती हैं।
आपकी अपनी जोड़ी ख़बरें, सेटिंग, श्रेणियाँ और मेनू सुरक्षित रहते हैं। जब तक डेमो डेटा है, डैशबोर्ड पर याद दिलाने वाली पट्टी दिखती है।

## 5. इंस्टॉल के बाद (ज़रूरी चेकलिस्ट)
1. सर्वर से **`/install` फ़ोल्डर हटा दें**। विज़ार्ड वैसे भी लॉक हो जाता है, पर हटाना सबसे सुरक्षित है।
2. **SSL** लगाएँ: cPanel → SSL/TLS Status → **Run AutoSSL**। फिर `config/env.php` में `APP_URL` को `https://` कर दें।
3. **ईमेल (SMTP)**: एडमिन → सेटिंग → ईमेल। होस्टिंग का ईमेल खाता (cPanel → Email Accounts → *Connect Devices* में SMTP जानकारी) या Gmail App Password डालें, फिर "टेस्ट मेल भेजें"। पासवर्ड रीसेट और OTP इसी से जाते हैं।
4. **दो-चरण लॉगिन (OTP)**: SMTP ठीक चलने के बाद सेटिंग → सुरक्षा में चालू करें।
5. **डेमो डेटा हटाएँ** (एडमिन → सिस्टम), अगर जोड़ा था।
6. **पहला बैकअप**: एडमिन → बैकअप → बनाएँ → डाउनलोड करें।
7. `config/env.php` में `DEBUG` हमेशा `false` रखें। यह फ़ाइल किसी को न दें।

### शेड्यूल (cron) की ज़रूरत नहीं
तय समय पर ख़बर प्रकाशित होना, न्यूज़लेटर, पुश सूचनाएँ, सफ़ाई और ऑटो-बैकअप साइट पर आने वाले ट्रैफ़िक से अपने-आप चलते हैं (मिनट में अधिकतम एक बार)।
साइट पर ट्रैफ़िक बहुत कम हो, तो cPanel → **Cron Jobs** में हर 5 मिनट पर यह जोड़ सकते हैं (वैकल्पिक):
```
*/5 * * * * curl -s https://आपका-डोमेन/ > /dev/null
```

## सुरक्षा जो पहले से लगी है
- `app/`, `config/`, `storage/`, `database/`, `routes/`, `modules/`, `docs/` बाहर से नहीं खुलते (`.htaccess` + हर फ़ोल्डर में अलग `.htaccess`)।
- `public/uploads/` में PHP फ़ाइल नहीं चल सकती।
- `.sql`, `.log`, `.lock`, `.ini`, `.json`, `.md`, `.bak` जैसी फ़ाइलें बाहर से बंद।
- Nginx वाली होस्टिंग हो (बहुत कम), तो होस्टिंग सपोर्ट से ये नियम लगवाएँ: सब अनुरोध `index.php` पर, और ऊपर वाले फ़ोल्डर `deny all`।

## समस्या और हल

| समस्या | हल |
|---|---|
| होमपेज खुलता है, बाकी पेज 404 | `.htaccess` अपलोड नहीं हुई (छुपी फ़ाइलें दिखाकर जाँचें), या mod_rewrite बंद है |
| सब-फ़ोल्डर में URL काम नहीं करते | `.htaccess` में `# RewriteBase /news/` लाइन से `#` हटाएँ और फ़ोल्डर का नाम लिखें |
| "डेटाबेस से कनेक्ट नहीं" | होस्ट `localhost` रखें; डेटाबेस/यूज़र नाम में cPanel का उपसर्ग (`user_`) जोड़ें; यूज़र को डेटाबेस से जोड़ा है या नहीं देखें |
| अपलोड नहीं हो रहा / "फ़ाइल बहुत बड़ी" | `public/uploads` की अनुमति 755; `upload_max_filesize` और `post_max_size` बढ़ाएँ (कदम 2) |
| तस्वीर छोटी नहीं हो रही, WebP नहीं बन रहा | PHP में `gd` एक्सटेंशन चालू करें |
| ईमेल नहीं जा रहा | सेटिंग → ईमेल में SMTP डालकर "टेस्ट मेल" भेजें; गड़बड़ी वहीं दिखेगी; `storage/logs/mail-*.log` भी देखें |
| OTP न आने से लॉगिन अटका | `config/env.php` में `'TWO_FACTOR_BYPASS' => true` जोड़ें, लॉगिन करके SMTP ठीक करें, फिर वह लाइन हटा दें |
| सफ़ेद पेज / 500 | `storage/logs/app-*.log` देखें; ज़रूरत हो तो थोड़ी देर `DEBUG => true` करें, फिर वापस `false` |
| "बहुत ज़्यादा अनुरोध" (429) | कुछ मिनट रुकें; यह लॉगिन/फ़ॉर्म की सुरक्षा सीमा है |
| इंस्टॉल के बीच "समय सीमा ख़त्म" | `max_execution_time` 120 करें, फिर `/install/` दोबारा खोलकर आगे बढ़ें |
| दोबारा इंस्टॉल करना | `config/env.php` और `storage/installed.lock` हटाएँ, फिर `/install/` खोलें। डेटा अपने-आप नहीं मिटता: नया प्रीफ़िक्स लें या phpMyAdmin से पुरानी टेबल हटाएँ |

## लोकल कंप्यूटर पर (XAMPP / Laragon / WAMP)
प्रोजेक्ट को `htdocs/news` में रखें, phpMyAdmin में खाली डेटाबेस बनाएँ, `http://localhost/news/` खोलें और वही 7 कदम पूरे करें।
