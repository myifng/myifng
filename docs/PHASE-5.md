# Phase 5: वेबसाइट: होमपेज, श्रेणी, लोकेशन, ख़बर पेज, खोज, मोबाइल UI

## 1. लक्ष्य

- **होमपेज (§13, §14)**: पूरी तरह होमपेज बिल्डर से। हर चालू सेक्शन अपने ब्लॉक टेम्पलेट से बनता है (हीरो, ग्रिड, स्लाइडर, ताज़ा, श्रेणी, लोकेशन/मेरा शहर, ट्रेंडिंग, सबसे ज़्यादा पढ़ी, लाइव टीवी, कस्टम HTML)। डेस्कटॉप/मोबाइल पर दिखना सेक्शन की सेटिंग से। जिन ब्लॉक का मॉड्यूल अभी नहीं बना (वीडियो, गैलरी, वेब स्टोरी, ई-पेपर, विज्ञापन, न्यूज़लेटर), वे चुपचाप छिपे रहते हैं।
- **हेडर**: ब्रेकिंग/ताज़ा ख़बरों की चलती पट्टी (ब्रेकिंग फ़्लैग वाली ख़बरें, न हों तो ताज़ा), ट्रेंडिंग पट्टी (फ़ीचर्ड टॉपिक + ट्रेंडिंग टैग), खोज बटन।
- **ख़बर पेज** `/news/{slug}`: ब्रेडक्रम्ब, किकर, शीर्षक, बाइलाइन (रिपोर्टर, जगह, समय, अपडेट), शेयर (WhatsApp, Facebook, X, लिंक कॉपी), इमेज, सुधार सूचना, वीडियो/ऑडियो, लेख, गैलरी, टैग, संबंधित ख़बरें (हाथ से चुनी + उसी श्रेणी की), साइडबार (ताज़ा, सबसे ज़्यादा पढ़ी)। SEO: canonical, Open Graph, `NewsArticle` + `BreadcrumbList` JSON-LD। व्यू गिनती (एक सत्र में एक बार, बॉट नहीं)।
- **श्रेणी पेज** `/category/{slug}`: उप-श्रेणियों की पट्टी, पहली बड़ी ख़बर + सूची, पेज नंबर; उप-श्रेणी की ख़बरें मुख्य श्रेणी में भी।
- **लोकेशन पेज** `/uttar-pradesh/`, `/uttar-pradesh/maharajganj/` (और `/…/local-news/`): नीचे की लोकेशन (ज़िले/शहर) की पट्टी, "इसे मेरा शहर बनाएँ", नीचे की सभी लोकेशन की ख़बरें।
- **टॉपिक** `/topic/{slug}` (विशेष सेक्शन: बैनर + रंग), **टैग** `/tag/{slug}`, **ताज़ा** `/latest`।
- **खोज** `/search?q=`: शीर्षक/सार/टैग में, श्रेणी से छाँटना, noindex।
- **मोबाइल UI**: नीचे की पट्टी (होम, ताज़ा, मेरा शहर, खोज), सभी पेज 360px तक।

## 2. डेटाबेस (migration `000005`)

- `news` पर FULLTEXT नहीं (हिंदी के लिए MySQL का FULLTEXT भरोसेमंद नहीं); खोज `LIKE` + इंडेक्स, सीमित नतीजे।
- `news` पर इंडेक्स `(status, deleted_at, views)` (सबसे ज़्यादा पढ़ी) और `(is_breaking, status, published_at)` (टिकर)।

## 3. रूट (वेबसाइट)

| पता | काम |
|---|---|
| `/` | होमपेज |
| `/news/{slug}` | ख़बर |
| `/category/{slug}` | श्रेणी |
| `/topic/{slug}`, `/tag/{slug}` | टॉपिक, टैग |
| `/latest` | ताज़ा ख़बरें |
| `/search?q=` | खोज |
| `/{राज्य}/{ज़िला}/…` | लोकेशन (सबसे आख़िर में, ताकि बाकी रास्ते पहले मिलें; एडमिन रूट अब पहले लोड होते हैं) |

## 4. कोड

- **Controllers (Front)**: `HomeController`, `NewsController` (show), `CategoryController`, `LocationController`, `TopicController` (टॉपिक + टैग), `SearchController` (खोज + ताज़ा)
- **Services**: `NewsQuery` (सिर्फ़ प्रकाशित ख़बरें: ताज़ा, श्रेणी, लोकेशन, टॉपिक, टैग, खोज, सबसे ज़्यादा पढ़ी, संबंधित, टिकर), `HomeRenderer` (सेक्शन → HTML, 5 मिनट कैश), `SeoService` (JSON-LD)
- **Views**: `front/home`, `front/article`, `front/listing` (श्रेणी/लोकेशन/टॉपिक/टैग/ताज़ा/खोज एक ही टेम्पलेट), `front/blocks/*`, `partials/front/card`, `ticker`, `bottom-nav`

## 5. अनुमतियाँ

सब सार्वजनिक। सिर्फ़ `published` + `published_at <= अभी` + ट्रैश में नहीं। ड्राफ़्ट/शेड्यूल/बंद ख़बर का URL 404 (स्टाफ़ के लिए एडमिन प्रीव्यू)। बंद श्रेणी/लोकेशन/टॉपिक 404।

## 6. सुरक्षा और प्रदर्शन

| बात | उपाय |
|---|---|
| XSS | सब आउटपुट `e()`; लेख सेव के समय sanitize; JSON-LD `JSON_HEX_TAG` |
| खोज से DB पर बोझ | क्वेरी 2-100 अक्षर, LIKE escape, 20 प्रति पेज, अधिकतम 50 पेज |
| पेज नंबर से बोझ | `?page` 1-500 |
| व्यू गिनती में धोखा | सत्र में एक ख़बर एक बार, बॉट user-agent नहीं गिने जाते |
| तेज़ी | होमपेज सेक्शन का HTML कैश (5 मिनट; ख़बर प्रकाशित/बदलने पर साफ़); "मेरा शहर" वाला सेक्शन कैश नहीं; इमेज lazy + WebP |
| शेड्यूल की ख़बर समय से पहले | `published_at <= NOW()` हर क्वेरी में |

## 7. टेस्ट के नतीजे (सब पास)

| जाँच | नतीजा |
|---|---|
| अपडेट / नया इंस्टॉल | एक क्लिक में migration 000005 (इंडेक्स + होमपेज पर "होम पर दिखाएँ" वाली श्रेणियों के सेक्शन (नए इंस्टॉल में 8: 1 बड़ा, बाकी आधी चौड़ाई में)); नए prefix पर पाँचों migration, दोबारा चलाने पर कुछ नहीं दोहराया |
| पेज | होम, ताज़ा (पेज 2), श्रेणी, उप-श्रेणी, राज्य, ज़िला, शहर, `/…/local-news`, टॉपिक, टैग, खोज, ख़बर, पुराने पेज (`/page/…`), एडमिन और `/api` रूट: सब 200; ग़लत श्रेणी/लोकेशन/ख़बर 404 |
| दिखने के नियम | ड्राफ़्ट, भविष्य के समय वाली, ट्रैश की ख़बर 404; बंद श्रेणी 404; एडमिन प्रीव्यू में ड्राफ़्ट `noindex` के साथ |
| व्यू गिनती | एक सत्र में 3 बार खोलने पर 1, Googlebot 0, नया पाठक 1 |
| खोज | `<script>` escape होकर दिखा; `%%` से सब नहीं मिला (LIKE escape); 500 अक्षर की खोज और `page=999999` बिना त्रुटि |
| SEO | ख़बर पर canonical, `og:type=article`, `article:published_time`, `NewsArticle` + `BreadcrumbList`; होम पर `WebSite` + `SearchAction` |
| होमपेज | सेक्शन बिल्डर के क्रम से; वीडियो/गैलरी/ई-पेपर/विज्ञापन/न्यूज़लेटर (आगे के phase) छिपे; "मेरा शहर" चुनने के बाद होम पर उसी शहर का सेक्शन और ज़िलों के टैब; ख़बर आर्काइव/प्रकाशित होते ही होम का कैश साफ़ |
| UI | Playwright: डेस्कटॉप 1440px और मोबाइल 390px (कोई आड़ा स्क्रॉल नहीं), खोज पट्टी, टैब, "इसे मेरा शहर बनाएँ", नीचे की मोबाइल पट्टी; कोई JavaScript त्रुटि नहीं |

## 8. ध्यान दें

- "सबसे ज़्यादा पढ़ी" = पिछले X दिन में प्रकाशित ख़बरों के कुल व्यूज़। रोज़ के व्यूज़ का हिसाब Phase 13 (एनालिटिक्स) में।
- श्रेणी/लोकेशन/टॉपिक के मेनू लिंक अब वेबसाइट पर दिखते हैं।
- सुझाव: होमपेज बिल्डर में "ताज़ा ख़बरें" सेक्शन हीरो के बीच वाले कॉलम जैसा ही है; चाहें तो उसे बंद कर दें।
