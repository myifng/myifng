# Phase 8: ई-पेपर

## 1. लक्ष्य (§40)

- **संस्करण (Edition)**: मुख्य / राज्य / ज़िला / शहर संस्करण, हर एक की लोकेशन (राज्य, ज़िला, शहर), डिफ़ॉल्ट संस्करण।
- **अंक (Issue)**: संस्करण + तारीख़ (एक संस्करण की एक तारीख़ का एक अंक), PDF, कवर (पहला पेज), पेज, प्रकाशन का समय (आगे का समय = शेड्यूल), मुफ़्त / प्रीमियम।
- **पेज बनाना, बिना सर्वर सॉफ़्टवेयर के**: एडमिन PDF चुनता है → उसके ही ब्राउज़र में pdf.js हर पेज को JPG बनाता है → पेज एक-एक कर अपलोड। साथ में पूरा PDF (डाउनलोड के लिए)। चाहें तो सीधे पेज की JPG/PNG फ़ोटो अपलोड करें। शेयर्ड होस्टिंग पर Imagick/Ghostscript की ज़रूरत नहीं।
- **पेज प्रबंधन**: थंबनेल, क्रम बदलना, पेज का नाम (मुख्य पृष्ठ, खेल…), बदलना, हटाना।
- **हॉटस्पॉट (लेख वाले हिस्से)**: पेज पर आयत बनाकर उसे किसी ख़बर या लिंक से जोड़ना; पाठक उस हिस्से पर टैप करे तो ख़बर खुले।
- **पाठक (Reader)**: थंबनेल, पेज आगे-पीछे, पेज चुनें, ज़ूम (बटन, डबल-टैप, पिंच/ड्रैग), फ़ुलस्क्रीन, मोबाइल स्वाइप, कीबोर्ड, संस्करण चुनें, तारीख़ चुनें, महीने का आर्काइव (कवर वाला कैलेंडर), PDF डाउनलोड (सेटिंग से), शेयर।
- **प्रीमियम का ढाँचा**: अंक पर `access` (free/premium)। प्रीमियम अंक में सिर्फ़ पहले N पेज (सेटिंग) सबको; बाकी स्टाफ़ को। Phase 11 के पाठक खाते/सदस्यता यहीं `EpaperService::canRead()` में जुड़ेंगे।
- होमपेज का "ई-पेपर" ब्लॉक (आज के कवर), डैशबोर्ड कार्ड, मेनू का ई-पेपर लिंक।

## 2. डेटाबेस (migration `000008`)

| टेबल | मुख्य कॉलम |
|---|---|
| `epaper_editions` | name, slug, type (main/state/district/city), location_id, description, is_default, status, sort_order |
| `epaper_issues` | edition_id, issue_date (unique साथ में), title, pdf, pdf_size, cover, page_count, access (free/premium), status (draft/published), publish_at, views, created_by |
| `epaper_pages` | issue_id, page_no, image, thumb, width, height, label |
| `epaper_hotspots` | page_id, x, y, w, h (पेज का %), news_id, url, label |

फ़ाइलें: `public/uploads/epaper/{वर्ष}/{महीना}/{अंक}-{रैंडम}/` (PHP चलना पहले से बंद)। सेटिंग ("लाइव टीवी और ई-पेपर" टैब): ई-पेपर चालू, PDF डाउनलोड, प्रीमियम में मुफ़्त पेज, PDF की अधिकतम साइज़।

## 3. रूट

| पता | काम | अनुमति |
|---|---|---|
| `/epaper` | संस्करण चुनें + आज के कवर | सार्वजनिक |
| `/epaper/{संस्करण}` | उस संस्करण का ताज़ा अंक | सार्वजनिक |
| `/epaper/{संस्करण}/{YYYY-MM-DD}` | रीडर (`?page=3`) | सार्वजनिक |
| `/epaper/{संस्करण}/archive?month=2026-09` | आर्काइव | सार्वजनिक |
| `/epaper/{संस्करण}/{तारीख़}/pdf` | PDF डाउनलोड | सेटिंग + मुफ़्त अंक |
| `/admin/epaper…` | अंक, पेज अपलोड/क्रम/हॉटस्पॉट | epaper.view/create/edit/delete/publish |
| `/admin/epaper/editions…` | संस्करण | epaper.edit |

## 4. कोड

- **Models**: `EpaperEdition`, `EpaperIssue`, `EpaperPage`, `EpaperHotspot`
- **Service**: `EpaperService` (प्रकाशित क्वेरी, फ़ाइल का फ़ोल्डर, पेज इमेज सेव + थंबनेल GD से, PDF जाँच, पेज नंबर ठीक करना, `canRead()`, फ़ाइलें हटाना)
- **Controllers**: `Admin\EpaperController` (अंक + पेज + हॉटस्पॉट, AJAX), `Admin\EpaperEditionController`, `Front\EpaperController`
- **JS**: एडमिन में PDF → पेज (लोकल `pdfjs-dist` 3.11, Apache-2.0, सिर्फ़ इस पेज पर), पेज अपलोड की कतार और प्रगति, हॉटस्पॉट ड्रॉ; वेबसाइट पर रीडर

## 5. अनुमतियाँ

- `epaper.view` सूची, `epaper.create` नया अंक, `epaper.edit` पेज/हॉटस्पॉट/संस्करण, `epaper.delete`, `epaper.publish` प्रकाशित/शेड्यूल। Editor के पास अभी सिर्फ़ `epaper.view` (Phase 1 से); ई-पेपर डेस्क को रोल स्क्रीन से दें।

## 6. सुरक्षा

| जोखिम | उपाय |
|---|---|
| नकली इमेज/PDF | finfo MIME + `getimagesize`; इमेज GD से दोबारा सेव (अंदर छिपा कोड हटे); PDF `%PDF-` से शुरू हो; साइज़ सीमा |
| अपलोड फ़ोल्डर में PHP | `public/uploads` में PHP चलना बंद (Phase 1); नाम रैंडम, एक्सटेंशन हम तय करते हैं |
| प्रीमियम पेज का लीक | बंद पेज की इमेज HTML में नहीं; फ़ोल्डर/फ़ाइल नाम रैंडम (अंदाज़ा नहीं लग सकता); प्रीमियम PDF डाउनलोड नहीं |
| ड्राफ़्ट/शेड्यूल अंक | सार्वजनिक क्वेरी: `status = published AND publish_at <= NOW()` |
| हॉटस्पॉट लिंक | सिर्फ़ ख़बर ID या http(s)/`/` लिंक; निर्देशांक 0-100% तक सीमित |
| CSRF / अनुमति | सारे POST/PUT/DELETE पर CSRF, हर रूट पर `can:` |

## 7. जाँच के नतीजे

| जाँच | नतीजा |
|---|---|
| PDF → पेज | 4 पेज की PDF ब्राउज़र में (pdf.js) 4 JPG पेज बनी, एक-एक कर अपलोड, प्रगति दिखी; PDF भी सेव हुई |
| पेज प्रबंधन | क्रम बदलना (← →), नाम, हटाना बिना रीलोड; "सारे पेज हटाएँ" से अंक ड्राफ़्ट |
| अपलोड की जाँच | `.jpg` नाम वाली PHP फ़ाइल, नकली PDF (इमेज को `.pdf` नाम): दोनों रुकीं; असली इमेज GD से दोबारा सेव + थंबनेल |
| नियम | एक संस्करण की एक तारीख़ का एक अंक; बिना पेज प्रकाशन रुका; आगे का प्रकाशन समय = 404 जब तक समय न आए |
| हॉटस्पॉट | पेज पर खींचकर 2 आयत; ख़बर खोजकर जोड़ना; बिना ख़बर/लिंक वाला रुका; रीडर में दोनों लिंक |
| रीडर | अकेला संस्करण हो तो `/epaper` सीधे रीडर; आगे/पीछे, कीबोर्ड, पेज चुनें, थंबनेल, ज़ूम 200%, `?page=` URL; PDF डाउनलोड (attachment) |
| मोबाइल | स्वाइप से पेज बदला; थंबनेल नीचे पट्टी में; 390px पर क्षैतिज स्क्रॉल नहीं (रीडर, आर्काइव, एडमिन) |
| प्रीमियम | बिना लॉगिन: 2 पेज खुले, तीसरा "प्रीमियम" (उसकी इमेज का पता HTML में नहीं); स्टाफ़ को तीनों; प्रीमियम PDF डाउनलोड 404 |
| आर्काइव / होमपेज | कैलेंडर में कवर के साथ दिन; होमपेज ब्लॉक "आज का ई-पेपर" |
| अनुमति | Editor: सूची/अंक देख सकता है, बनाना/संस्करण/हटाना 403; Reporter 403 |
| CSRF | 5 POST रूट पर ग़लत टोकन → 419 |
| नया इंस्टॉल | 8 माइग्रेशन, "मुख्य संस्करण" अपने आप; दोबारा चलाने पर कुछ नहीं बदला |

**साथ में सुधार (Phase 7):** फ़ुटर "उपयोगी लिंक" में "लाइव टीवी" दो बार आ रहा था (मेनू-प्रकार वाला लिंक पहले से था)। Phase 7 का माइग्रेशन ठीक किया और यह माइग्रेशन पुरानी साइटों पर दोहराव हटा देता है।

**ध्यान दें:** बड़ी PDF के लिए सर्वर की `upload_max_filesize` / `post_max_size` बढ़ानी पड़ सकती है (एडमिन में सीमा दिखती है)। पेज की इमेज अलग-अलग अपलोड होती हैं, इसलिए पेज बनाने पर यह सीमा सिर्फ़ PDF सेव करने में लागू होती है।
