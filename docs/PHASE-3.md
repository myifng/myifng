# Phase 3: श्रेणी, टॉपिक, टैग, लोकेशन, मीडिया लाइब्रेरी

## 1. लक्ष्य

- **श्रेणी (§11)**: श्रेणी → उप-श्रेणी (2 स्तर)। नाम, अंग्रेज़ी स्लग, आइकन, इमेज, रंग, SEO, मेनू में/होमपेज पर दिखे या नहीं, क्रम, स्थिति। ख़बरों वाली श्रेणी हटाई नहीं जा सकती।
- **टॉपिक और विशेष सेक्शन (§11)**: एक ही टेबल में `type` = `topic` (जैसे "लोकसभा चुनाव") या `special` (विशेष कवरेज: बैनर, रंग, अलग पेज)। फ़ीचर्ड/ट्रेंडिंग टॉपिक।
- **टैग (§11)**: खोज, उपयोग-गिनती, बल्क हटाना, **मर्ज** (दो मिलते-जुलते टैग एक करना)।
- **लोकेशन इंजन (§12)**: एक टेबल, 8 स्तर: देश → राज्य → मंडल → ज़िला → तहसील → ब्लॉक → शहर → मोहल्ला।
  - URL में सिर्फ़ पढ़ने वाले स्तर: `/uttar-pradesh/`, `/uttar-pradesh/maharajganj/` (देश और मंडल URL में नहीं; ज़िले को बाद में किसी मंडल के नीचे रखने से URL नहीं बदलता)
  - `path` कॉलम में पूरा पता पहले से सेव (तेज़ खोज)
  - भारत के सभी 28 राज्य + 8 केंद्र शासित प्रदेश, और उत्तर प्रदेश के सभी 75 ज़िले पहले से
  - CSV से बल्क इम्पोर्ट
  - **मेरा शहर**: वेबसाइट पर पाठक अपना शहर चुने (कुकी में याद); Phase 5 में "आपके शहर की ख़बरें" इसी से
- **मीडिया लाइब्रेरी (§56, §57)**: इमेज, वीडियो, ऑडियो, PDF/दस्तावेज़। फ़ोल्डर, खोज, फ़िल्टर, alt/कैप्शन/क्रेडिट/कीवर्ड, बदलना (Replace), ट्रैश।
  - मूल फ़ाइल कभी नहीं बिगड़ती; उससे बनते हैं: large (1600), medium (800), thumb (400×225), और सर्वर चाहे तो हर एक का **WebP**
  - वॉटरमार्क (सेटिंग से), सिर्फ़ large/medium पर
  - Replace पर पुरानी मूल फ़ाइल `storage/private/replaced/` में सुरक्षित
  - **मीडिया पिकर**: कहीं भी "लाइब्रेरी से चुनें" (श्रेणी इमेज, एडिटर, आगे ख़बरें)
  - एडिटर की इमेज अपलोड अब सीधे लाइब्रेरी में

## 2. डेटाबेस (migration `000003`)

| टेबल | मुख्य कॉलम |
|---|---|
| `categories` | parent_id, name, slug (unique), description, icon, image, color, meta_title, meta_description, show_in_menu, show_on_home, sort_order, status, language_id, timestamps |
| `topics` | type (topic/special), name, slug (unique), description, image, banner, color, is_featured, sort_order, status, meta_title, meta_description, timestamps |
| `tags` | name, slug (unique), description, usage_count, timestamps |
| `locations` | parent_id, type, name, name_en, slug, path (unique), code, is_popular, show_in_menu, status, sort_order, meta_title, meta_description, timestamps |
| `media_folders` | parent_id, name, created_by |
| `media` | folder_id, file, original_name, mime, kind (image/video/audio/document), size, width, height, variants (JSON), title, alt, caption, credit, keywords, uploaded_by, timestamps, deleted_at |

डिफ़ॉल्ट डेटा: 14 श्रेणियाँ (कुछ उप-श्रेणियों के साथ), भारत + 36 राज्य/UT + UP के 75 ज़िले; मुख्य मेनू और फ़ुटर में श्रेणियाँ।

## 3. रूट (एडमिन)

| पता | काम | अनुमति |
|---|---|---|
| /admin/categories (+create, {id}/edit, move, DELETE) | श्रेणी | categories.* |
| /admin/topics (+…) | टॉपिक/विशेष सेक्शन | topics.* |
| /admin/tags (+merge, bulk) | टैग | tags.* |
| /admin/locations?parent= (+create, edit, import, search JSON) | लोकेशन | locations.* |
| /admin/media (+upload, {id} update/replace/trash/restore/purge, folders, browse JSON) | मीडिया | media.* (purge: media.manage) |
| /api/locations?q= , POST /api/my-city | मेरा शहर (वेबसाइट) | सार्वजनिक (CSRF, रेट लिमिट) |

## 4. कोड

- **Controllers**: `Admin\CategoryController`, `TopicController`, `TagController`, `LocationController`, `MediaController`; `Front\LocationApiController`
- **Models**: `Category`, `Topic`, `Tag`, `Location`, `Media`, `MediaFolder`
- **Services**: `MediaService` (अपलोड, वेरिएंट, WebP, वॉटरमार्क, replace), `LocationService` (path, पेड़, खोज, इम्पोर्ट), `TaxonomyService` (स्लग, पेड़, हटाने की जाँच)
- **Repositories**: `MediaRepository`, `LocationRepository`
- **Helpers**: `media_img()` (WebP के साथ `<picture>`), `media_variant()`

## 5. अनुमतियाँ

`categories/topics/tags/locations/media` के `view, create, edit, delete`; `media.manage` = ट्रैश से स्थायी रूप से हटाना और फ़ोल्डर प्रबंधन; टैग मर्ज = `tags.edit` + `tags.delete`।

## 6. सुरक्षा

| जोखिम | बचाव |
|---|---|
| ख़तरनाक फ़ाइल | MIME (finfo) + extension allowlist; SVG मीडिया में नहीं; uploads में PHP बंद; रैंडम नाम |
| बड़ी फ़ाइल/बहुत अपलोड | प्रकार-वार सीमा; अपलोड पर रेट लिमिट |
| मूल फ़ाइल खोना | मूल अछूती; replace पर पुरानी `storage/private` में |
| श्रेणी/लोकेशन हटाने से टूटे लिंक | उप-श्रेणी/बच्चे/इस्तेमाल हो तो हटाना मना |
| CSV इम्पोर्ट | आकार/पंक्ति सीमा, हर पंक्ति की जाँच, ट्रांज़ैक्शन |
| मेरा शहर API | CSRF, रेट लिमिट, सिर्फ़ मौजूद लोकेशन ID, HttpOnly नहीं (JS पढ़ती है) पर सिर्फ़ ID |
| पेड़ में चक्र (A का parent B, B का A) | parent बदलते समय जाँच |

## 7. स्क्रीन

श्रेणी पेड़ (ऊपर/नीचे, उप-श्रेणी जोड़ें) · श्रेणी फ़ॉर्म (आइकन प्रीव्यू, इमेज पिकर, SEO) · टॉपिक सूची (टैब, फ़ीचर्ड स्टार) · टॉपिक फ़ॉर्म (इमेज + बैनर) · टैग (जल्दी जोड़ें, मर्ज, बल्क) · लोकेशन ब्राउज़र (ब्रेडक्रम्ब से परत-दर-परत, खोज) · लोकेशन फ़ॉर्म (ऊपर वाली लोकेशन खोज-चयन) · CSV इम्पोर्ट · मीडिया लाइब्रेरी (ड्रैग-ड्रॉप अपलोड, फ़ोल्डर, ग्रिड, बल्क) · मीडिया विवरण (आकार/WebP सूची, कहाँ इस्तेमाल, replace, दोबारा बनाएँ) · मीडिया पिकर (modal) · सेटिंग → इमेज और वॉटरमार्क · वेबसाइट हेडर में "मेरा शहर"

## 8. टेस्ट के नतीजे (सब पास)

| जाँच | नतीजा |
|---|---|

| नया इंस्टॉल | नए prefix पर तीनों migration + CoreSeeder; दोबारा चलाने पर कुछ नहीं दोहराया; सभी श्रेणियाँ भाषा से जुड़ीं |

| टॉपिक/टैग | ग़लत प्रकार 422 संदेश; फ़ीचर्ड टॉगल; कई टैग एक साथ, दोहराव छोड़े; मर्ज में target चुनना ज़रूरी, गिनती जुड़ी, ख़बर-टैग रिश्ते बिना दोहराव के नए टैग पर गए; मौजूदा नाम पर rename मना |
| लोकेशन | नया शहर `/uttar-pradesh/maharajganj/nautanwa/`; ज़िले को मंडल के नीचे ले जाने पर URL नहीं बदला; स्लग बदलने पर नीचे वाली लोकेशन के path भी बदले; चक्र (A→B→A) मना; बच्चों के साथ स्तर बदलना मना; आरक्षित स्लग (`admin`) और दोहराया path मना; अंग्रेज़ी नाम में HTML मना |

| RBAC | Editor: श्रेणी/लोकेशन सिर्फ़ देख सकता है (बनाने पर 403), टॉपिक/टैग/मीडिया पूरा; Reporter: सिर्फ़ मीडिया देखना/अपलोड, बाकी सब 403; साइडबार में सिर्फ़ अनुमति वाले मॉड्यूल |
| UI | Playwright: पिकर से श्रेणी इमेज, एडिटर में लाइब्रेरी से इमेज, लोकेशन खोज-चयन (कीबोर्ड), टैग मर्ज सूची, ड्रैग-ड्रॉप अपलोड की प्रगति, मेरा शहर (डेस्कटॉप + मोबाइल); कोई JavaScript त्रुटि नहीं |

## 9. ध्यान दें

- श्रेणी/टॉपिक/लोकेशन के सार्वजनिक पेज Phase 5 में बनेंगे। तब तक मेनू में जोड़े गए इनके लिंक वेबसाइट पर छिपे रहते हैं (404 से बचाव); मेनू बिल्डर में "अभी वेबसाइट पर नहीं दिखेगा" लिखा आता है।
- टेक्स्ट वॉटरमार्क GD के अपने फ़ॉन्ट से बनता है, इसलिए सिर्फ़ अंग्रेज़ी अक्षर। हिंदी के लिए PNG लोगो वॉटरमार्क इस्तेमाल करें।
- रिपोर्टर अभी पूरी लाइब्रेरी देख सकता है; "सिर्फ़ अपनी फ़ाइलें" का नियम रिपोर्टर मॉड्यूल (Phase 6) के साथ।
